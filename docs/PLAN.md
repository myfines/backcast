# Backcast · 找到经得起时间检验的判断

目标：发现预测者 → 阅读历史合订本 → 检查证据 → 同口径对比 → 关注。

## 实施顺序
1. Python 单元测试先覆盖时间资格、无证据与虚假引用。
2. FastAPI / SQLite：真实案例、关注、纠错、导入、抽取、搜索与核验。
3. Next.js / Tailwind / ECharts：发现页、人物合订本、证据抽屉、对比、导入。
4. 本地启动、生产构建、API 与 Playwright 端到端测试，记录实际结果。

## 边界
- 不采集登录后内容，不做全网爬虫，不使用 BTC 案例。
- 首批四个案例为消费科技、新能源、航天、体育；真实公开来源，人工整理的转述，不冒充知乎原文。
- 每位预测者仅有少量样本，不能据此推荐专业能力。机构与个人明确区分。
- 历史原始版本未独立存证时，结果可复盘，但不计入严格预测成绩。
- 无模型配置时可用规则提取候选；无搜索配置时不产生自动事实结论。
- 本地优先，SQLite 单进程持久化；暂不接账号、跨用户权限和公开互联网发布。

## 目录
apps/web/app：前端；services/api：数据库、采集、模型/搜索适配器与判定；tests：单元/集成/E2E；docs：说明与运行记录。
